# Contributing to SwapLayer

Issues and pull requests are welcome. For a vulnerability, use the private
reporting route in [SECURITY.md](SECURITY.md) instead of a public issue.

Fork the repository, keep your change focused, explain its behavior and
compatibility impact, update the relevant docs, and include appropriate test
evidence. Never submit credentials, customer data, or production examples.
Contributions are provided under the repository's [MIT license](LICENSE);
preserve copyright and third-party license notices.

The owner (`@bezu-1`) reviews and approves external changes before merge.
New commits invalidate previous approval. Workflow and release configuration
receive the same owner review as application code.

PRs, issues, comments, and agent mentions cannot authorize coding agents, GitHub
Actions, paid agent-token use, or publishing credentials. Vendor-hosted GitHub
app access must also be restricted separately in the owner's account settings.
Only the owner starts manual workflows; contributors should include their local
test results. Do not request that an agent approve or merge its own work.

See [VERSIONING.md](VERSIONING.md) for the common versioning and release policy
and the README's development instructions for this package's local checks.
