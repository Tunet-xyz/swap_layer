# About the development notes

This folder keeps design notes from SwapLayer's 0.x development. They record
implementation decisions and do not describe current behavior; current
provider support is listed in [the documentation index](../README.md).

Contribution rules are in [CONTRIBUTING.md](../../CONTRIBUTING.md), local checks
in the README's [Development](../../README.md#development) section, and release
steps in the [release procedure](../RELEASE.md). Agents also follow
[AGENTS.md](../../AGENTS.md) and [VERSIONING.md](../../VERSIONING.md).
